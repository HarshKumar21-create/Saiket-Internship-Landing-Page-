# Landing Page

## Description
A responsive landing page built using HTML, CSS, and JavaScript. It focuses on clean UI design, responsiveness, and basic interactivity.

## Features
- Responsive design for all devices
- Clean and modern UI
- Structured sections (Hero, Cards, Footer)
- Basic JavaScript interactivity
- Lightweight and fast loading

## Tech Stack
- HTML5
- CSS3
- JavaScript

## How to Run
1. Clone the repository
2. Open index.html in browser
